# OBSERVATION-MEMO（観察記録メモ）

看護師など、日々の業務でちょっとした観察記録・メモをその場でサッと残したい人向けの、シンプルなメモアプリです。ログイン不要・1人で使う前提で作っています。

## 何のためのアプリか

- 対象（患者名・部屋番号など）・日時・内容を入力してメモを保存
- 日時を省略すると現在時刻が自動で入る
- メモは新しい順に一覧表示
- 一覧から編集・削除ができる（削除前に確認あり）
- キーワードで対象・内容を部分一致検索して絞り込める

## 使い方

`index.html` をブラウザで直接開くだけで動作します。インストールやビルドは不要です。

## なぜこの技術構成にしたか

フリーランスで受注しやすい「未経験可」「簡単なスクリプト修正」案件（LP修正や小規模な機能追加など）は、素のHTML/CSS/JavaScriptで動いていることが多いです。そうした案件に対応できることを示すポートフォリオとして、あえてフレームワークやビルドツールを使わず、

- HTML / CSS / JavaScriptのみ
- バックエンド・データベースなし（データはブラウザの`localStorage`に保存）
- ビルド不要でファイルを直接開けば動く

というシンプルな構成にしました。

## 技術構成

- HTML / CSS / JavaScript（フレームワーク・ライブラリ不使用）
- データ保存: ブラウザの`localStorage`（サーバーへの送信なし）
- ビルドツール: なし

## 対象外

- ログイン・ユーザー管理
- 複数人での共有
- サーバーへのデータ送信
